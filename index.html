Hardware

Wiring the five LEDs

Each LED sits on its own pin through a 220–270Ω resistor, with a shared ground rail back to the Arduino GND. USB powers the board — no external supply needed.

PinComponent
D2LED 1 + 270Ω (anode to resistor, cathode to − rail)
D3LED 2 + 270Ω
D4LED 3 + 270Ω
D5LED 4 + 270Ω
D6LED 5 + 270Ω
GNDBreadboard − rail
USBLaptop → Arduino (power + serial)
Source

Arduino sketch

Upload this with Arduino IDE (Board: Arduino UNO), then close the Serial Monitor before connecting from the website. The site sends text commands like M7 (bit0 = LED1 … bit4 = LED5) and the Arduino answers OK 7, shown in the “Arduino reply” chip.

// Hand Gesture LED Control - Arduino UNO (LEDs on D2..D6)
// Website sends text:  M<mask>  e.g. "M7" = LED1+2+3.   Arduino replies "OK 7"
const int LED_PINS[5] = {2, 3, 4, 5, 6};

void setMask(int m) {
  for (int i = 0; i < 5; i++) digitalWrite(LED_PINS[i], (m >> i) & 1);
}

void setup() {
  Serial.begin(9600);
  Serial.setTimeout(30);
  for (int i = 0; i < 5; i++) pinMode(LED_PINS[i], OUTPUT);
  // power-on self test: LEDs chase once, flash, then turn off
  for (int i = 0; i < 5; i++) { setMask(1 << i); delay(120); }
  setMask(31); delay(300); setMask(0);
  Serial.println("READY");
}

void loop() {
  if (Serial.available() > 0) {
    String s = Serial.readStringUntil('\n');
    s.trim();
    if (s.length() == 0) return;
    if (s[0] == 'M') {
      int m = s.substring(1).toInt() & 31;
      setMask(m);
      Serial.print("OK "); Serial.println(m);
    } else if (s[0] == 'P') {
      Serial.println("PONG");
    }
  }
}



Port busy? “Failed to open serial port” means another program holds the port — close Arduino IDE Serial Monitor and other tabs using the Arduino, then replug USB.

LEDs not turning on? Check in this order

  1. Upload this new sketch. An older sketch expects different data, so the LEDs ignore the website. The “Arduino reply” chip turns green when the right sketch is running.
  2. Power-on self-test: after upload (or when the page connects) the 5 LEDs should chase once and flash. If they don’t, it’s wiring: long leg → 270Ω → D2–D6, short leg → − rail, rail → GND.
  3. Serial Monitor test: set 9600 baud + “Newline”, type M31 → all LEDs on, M0 → off. Close the monitor before using the website.
  4. Hardware test buttons on the page switch LEDs without the camera.
